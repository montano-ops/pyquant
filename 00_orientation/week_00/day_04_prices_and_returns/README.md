# Day 4 — Prices, Returns, and Your First Charts

**Module 00 · Week 0 · ~90 min**

**Objective:** understand what a "price" in a dataset actually is (as-traded
vs adjusted), define simple and log returns properly, and produce your first
research-quality charts.

**Prerequisites:** day 2 (toolkit).

**Files:** lesson.md → exercise.ipynb → solution.ipynb → review.md

**Research connection:** every empirical paper's first table is built from
returns; adjusted vs unadjusted prices silently change results (a real source
of reproduction failures).

**Self-check:** why does the same stock's 10-year "return" differ by several
percent per year depending on which price column you use?
