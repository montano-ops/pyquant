# Data

This directory holds data plumbing for the course. **No market data is committed to git** —
you download it yourself and it is cached locally.

## Layout

```
data/
├── cache/          # auto-created parquet cache (gitignored)
├── fetch_sp500.py  # snapshot the current S&P 500 constituent list from Wikipedia
└── README.md
```

## Sources used by this course

| Source | What for | Notes |
|---|---|---|
| Yahoo Finance (via `yfinance`) | daily OHLCV, adjusted prices, dividends/splits, option chains | free, easy, **survivorship-biased** — you will learn exactly why that matters in module 05 |
| Ken French Data Library | Fama–French factors, momentum, reversal factors | the standard free factor source; `qrc.data.get_ff()` |
| Wikipedia | current index constituent lists | only *today's* list — never point-in-time |

## The honest limitations of free data (you will quantify these in module 05)

- **Survivorship bias**: Yahoo serves (mostly) *currently listed* securities. Delisted
  stocks are missing, so backtests on Yahoo universes are biased upward.
- **No point-in-time data**: you can easily get today's S&P 500 members; getting the
  members *as known on a past date* requires commercial data (CRSP/WRDS, Compustat PIT).
- **No historical bid/ask or depth**: we approximate trading frictions with models
  (module 12) and estimators (Corwin–Schultz, module 10).

Where a paper needs CRSP-quality data, the course says so explicitly and either
(a) reproduces on a biased-but-transparent universe and *audits the bias direction*,
or (b) reproduces the paper's *simulation* logic instead.

## Offline / no-internet mode

Every lesson notebook honours the `DATA_SOURCE` switch:

```python
DATA_SOURCE = "synthetic"   # simulated prices with realistic fat tails + vol clustering
```

Synthetic data is generated by `qrc.synth.synthetic_prices()` with fixed seeds, so
notebooks run deterministically anywhere. Simulated data is also a research tool:
when *you* control the true data-generating process, you can check whether your
method can actually find a signal that you *know* exists.
